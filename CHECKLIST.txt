TROUBLESHOOTING:

Problem: Import errors in IDE
Solution: Normal - will work at runtime. Run: pip install -r requirements.txt

Problem: "API Key not found"
Solution: Add keys to .env or enter in UI

Problem: "No module named 'tradingagents'"
Solution: Ensure you're in the correct directory and deps are installed

Problem: Analysis too slow
Solution: Use Groq provider or reduce research depth to 1

Problem: Too expensive
Solution: Use OpenRouter free models or Groq free tier
